🧠 AI-Powered Stroke Neuro-Rehabilitation Monitoring System

An Artificial Intelligence and Machine Learning Approach to Stroke Rehabilitation Monitoring

📌 Project Overview

The AI-Powered Stroke Neuro-Rehabilitation Monitoring System is a machine learning-based project designed to assist in monitoring stroke patients during their neuro-rehabilitation exercises.

The system uses human pose estimation and machine learning techniques to analyze body movements, evaluate exercise performance, identify incorrect postures, and support physiotherapists in tracking patients' rehabilitation progress.

The primary goal is to explore how Artificial Intelligence can contribute to accessible, efficient, and technology-assisted neuro-rehabilitation.

🎯 Project Objectives

- Monitor patient body movements during rehabilitation exercises.
- Extract body pose landmarks using pose estimation.
- Analyze movement patterns using Machine Learning.
- Classify exercise performance as Good or Bad.
- Identify incorrect exercise movements.
- Support physiotherapists in monitoring rehabilitation progress.
- Explore AI-based solutions for healthcare and neuro-rehabilitation.

🔬 Methodology

The proposed system follows these major steps:

1. Data Collection: Collect rehabilitation exercise movement data.
2. Pose Estimation: Extract body landmarks from patient movements.
3. Feature Extraction: Process and prepare pose landmark data.
4. Data Preprocessing: Prepare datasets for machine learning.
5. Model Training: Train a machine learning model using labelled movement data.
6. Movement Classification: Classify movements into Good and Bad categories.
7. Performance Monitoring: Analyze movement performance to support rehabilitation assessment.

📂 Dataset Structure

The project uses processed pose landmark data and corresponding labels.

Example:

dataset/
├── X_pose.npy
└── y_labels.npy

Labels:

- 0 = Good Movement
- 1 = Bad Movement
